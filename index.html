Admin Panel

Guidelines for uploading MCQs

  1. Click "Download Template" and open it in Microsoft Excel.
  2. Row 1 is the heading row. Keep it as it is. Start your MCQs from row 2.
  3. Use exactly 6 columns: A = Question, B = Option A, C = Option B, D = Option C, E = Option D, F = Correct Answer.
  4. Correct Answer must be one letter only: A, B, C or D.
  5. Every question needs all 4 options. Do not leave any cell empty and do not leave blank rows between questions.
  6. Save the file as .xlsx (Excel Workbook) or .csv. Only the first sheet is read.
  7. Select the course below, choose the file and press Check File. If there is no error, press Save Questions.
  8. Saved questions replace the old questions of that course. Use 25 questions for a full test. Each question is 1 mark.
